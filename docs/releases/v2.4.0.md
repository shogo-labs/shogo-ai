# Shogo 2.4.0 release write-up

Release plan, test plan, announcement drafts and rollback notes for v2.4.0. The
in-app What's New and the docs changelog entry live in
`apps/docs/changelog/2026-10-26-v2-4.md`.

The notes cover everything from `v2.3.0` to the release commit, including the
patches `v2.3.1` through `v2.3.13`, which shipped without release notes. The
test plan covers only what is new to production: `v2.3.13..<release commit>`
(65 commits at `0f5e14bd0`, 709 files, 8 Postgres + 8 SQLite migrations).

## Pre-flight (already checked)

- Production `api-secrets` in US and EU already have `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, `ZERNIO_API_KEY`, `ZERNIO_WEBHOOK_SECRET`. `ZERNIO_API_KEY` is **not optional** in the prod overlays, so a missing key would have stopped the api from starting.
- CI on `main` is green for the release commit.

## Tagging

1. Blockers above closed; the release commit's staging deploy is green.
2. `git tag -a v2.4.0 -m "Shogo 2.4.0" <release-commit> && git push origin v2.4.0`.
3. Watch `deploy.yml` for the tag: promote-images → deploy-us → deploy-eu → metal-runtime-image → dispatch-metal-agent-release → SDK publish. Desktop builds (macOS, Windows) are attached to the GitHub release.
4. Prepend the GitHub notes below: `gh release edit v2.4.0 --notes-file …`.
5. Merge this notes PR so docs.shogo.ai/changelog/v2-4 and the in-app What's New go out.
6. Post-deploy checks in prod: the runbook's pre/post-roll checks, a two-person huddle with notes, a new signup gets the $2 credit, `project_agents` ids match across regions, no new SigNoz alerts for 1 hour.
7. Then send the announcement email.

## GitHub release notes

Prepend this above the auto-generated download block on the published release.

```md
# Shogo 2.4: Huddles that take notes, and publishing from Shogo

In 2.4, huddles take their own notes, and you can bring your agent into the call by saying "hey Shogo". You can publish to your social accounts without leaving Shogo. Agents are easier to follow and to steer while they work, and your workspaces move with you between computers and the cloud.

## Huddles that take notes

- Group calls with a call window, reactions, polls and a chat for the call.
- Notes are on by default: a transcript that shows who said what, and a summary when the call ends.
- Live captions, and "hey Shogo" brings your workspace agent into the call.
- Pick your notification tone. A public huddle link no longer shows the starter's email.

## Publish to social from Shogo

- Turn on Social management, connect Instagram, TikTok and more, and publish to several accounts at once.
- One inbox for comments and DMs, comment-to-DM automations, and post analytics.

## Agents that keep moving

- One chat mode: Plan and Ask are gone, and you can still ask for a plan.
- Running agents sit in a dock above the composer with a Stop button. Queued messages can be sent now or removed.
- Up to 100 turns per thread, and a loop of 10 identical calls stops itself.
- Attachments upload before the turn, text-only models get image descriptions, and a refused image no longer breaks the chat.
- List models, Tripo 3D, more image and video models, a Video Editor project type, and 13 Marketplace agent packs.

## Your workspace, anywhere

- Export a whole workspace as one file and import it elsewhere.
- Several local workspaces on desktop, and your computer's workspaces in Shogo on the web.
- Invitations in the workspace switcher. Analytics → Heartbeats shows what each agent's heartbeat costs.

## A smoother IDE

- Drop files and folders anywhere in the IDE, preview PDFs, import a .shogo in one step.
- Cloud projects start on their source right away and load git history in the background.

## Also in this release

- Chat: `#` channel links, day dividers, profiles from names, reaction hover cards, message links as quotes, files open in the side panel.
- Voice: dictate with the mic, or record a voice note from the clip button.
- Desktop: updates and quitting wait for idle agents. Mobile: proper Back, a faster Home, the workspace you picked is remembered.
- New cloud accounts get $10 of credit, and paid plans have a 7-day free trial.

## Changed

- Full autonomy no longer blocks any command or file path. Pick another permission mode for guardrails.

## Fixed

- Replies no longer disappear when you switch chats or a new turn starts, and a finished background task reports once.
- Tables and code blocks in chat scroll again, image previews fit, and file paths in code aren't linkified.
- Deleting a project takes down its published site and its task logs.
```

## Rollback note

`Rollback Production` to `v2.3.13` is safe for the Kubernetes side:

- Every migration is additive except `project_agents_random_ids`, which only
  rewrites ids. A 2.3.13 api reads the new ids fine. The `UsageSource.promo`
  enum value stays; 2.3.13 never writes it.
- Promo credit granted under 2.4.0 stays in the wallet columns, and 2.3.13
  ignores it (it isn't spent until you roll forward).
- **Metal agent:** don't roll the node agent back past 2.3.0 (see the 2.3.0
  rollback note). Rolling the agent back from 2.4.0 to 2.3.13 is fine, but a
  2.3.13 agent always restores git history in the foreground, so cloud project
  opens get slower again.
- Chat modes: a 2.3.13 client sending `interactionMode` to a 2.4.0 api is
  ignored, and a 2.4.0 client never sends one to a rolled-back api, so both
  directions work.
