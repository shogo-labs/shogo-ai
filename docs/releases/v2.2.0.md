# Shogo 2.2.0 release write-up

Drafts of the external announcements for v2.2.0. The in-app What's New and the
docs changelog entry live in `apps/docs/changelog/2026-10-05-v2-2.md`.

Covers everything from `v2.1.0` to the release commit (`v2.1.1` shipped without
release notes).

## GitHub release notes

Prepend this above the auto-generated download block on the published release
(`gh release edit v2.2.0 --notes-file ...`).

```md
# Shogo 2.2: Workspaces and chats

In 2.2, your workspace is where your team and your agents work together. Everyone shares one chat, in Shogo or in the chat tool you already use. Every workspace is on every device. Agents in the workspace pick up what happens there and act for the right person.

## One chat for your team and your agents

- Workspace chat now has modes: run it natively in Shogo, bridge it to Slack, Microsoft Teams, or Google Chat, or turn it off.
- Agents are members of your channels. @mention one to hand it work, and agents can hand work to each other in the same thread, with limits that stop runaway chains.
- Each thread has an owner, so a reply that doesn't @mention anyone goes back to the agent already working on it.
- Agents can send a DM for you, clearly labeled as sent on your behalf.
- New workspace chats get titles automatically.

## A better place to talk

- Unread markers take you to the first new message, and "Mark unread" lets you come back to it later.
- Copy a link to any message. Opening it jumps to that message, even in an old thread.
- Paste or drag files into the composer.
- A full emoji picker with `:shortcodes:`.
- Rename channels and edit their topics.
- Queued messages and replies show up in the right place while an agent is responding, and streaming no longer lags.
- On phones, chat gets a new edge-to-edge glass layout.

## Every workspace, on every device

- Sign the desktop app in to Shogo Cloud and all of your cloud workspaces appear next to your local ones, live, with a Cloud badge.
- Your Personal workspace on desktop is the same one you use on web and mobile, with the same projects and chats.

## Workspaces that react

- A new Automations tab in Settings. Workspace events start work on their own:
  - Events: a member joins, a GitHub webhook arrives, a connected app fires a trigger.
  - What they can start: an agent, a project, a code hook, or a signed webhook.
- "New automation" opens the workspace agent with the request filled in, so you describe what you want in plain words.
- Marketplace apps list what they need from your workspace, and you approve it before installing.

## Agents act for the person who asked

- Choose, per integration, whether agents use the project's account or the account of the person who asked them, in chat or through an automation.
- If that person hasn't connected an account yet, they get a link in the chat. The conversation picks up again once they connect.
- This carries across agent-to-agent calls in the workspace. Only workspace admins and the project creator can change it.

## Also in this release

- **GitHub:** connect with a token or the GitHub App, push and pull, and switch branches from chat. Astro and Eleventy sites build and preview automatically.
- **Meetings:** transcripts stream in real time.
- **Desktop:**
  - Fn push-to-talk dictation that types into any app.
  - Permission onboarding and a new Computer and files settings tab.
  - Buddy colors and an animated login screen.
- **IDE:** your unsaved edits survive a reload, renames and deletes are safe, and there's faster search and Quick Open.

## Fixes since 2.1.0

- Fixed an iOS crash at launch.
- Workspace runtimes no longer revert projects to the starter.
- Corrected billing usage and team member emails.
- The "Starting API server..." gate no longer hangs on stacks without a sidecar.
```
