In 2.3, your agents take on bigger jobs. They plan the work on a board in your channel, keep going while it runs, and report back when it's done. Your team gets huddles, voice notes, and roles to control who can do what.

<!-- truncate -->

## Work boards in your channels

- **Boards in team channels.** Ask an agent to organize a project and it sets up a board in the channel, adds cards, and moves them as the work happens.
- **See who's working.** A card shows a spinner while an agent works on it. Summaries and descriptions render as formatted text.
- **On for everyone.** Work boards are on by default in every workspace.

## Talk the way you want

- **Huddles.** Start an audio or video call in any channel or DM, and share your screen. Headphones show next to anyone in a huddle. Huddles work on web and desktop.
- **Voice notes.** Record, send, and play voice notes in channels and DMs.
- **Profile pictures.** Set a photo for your account.
- **A note to yourself.** A private conversation with just you, for drafts and reminders.
- **Starred DMs.** Pin the conversations you use most to the top of the DMs tab.
- **Mentions.** @-mentions are highlighted. If you mention someone who isn't in the channel, Shogo offers to add them.
- **Shared files.** Files get a card with a preview and a download button. On desktop they open in their own window.
- **Channels.** Archive channels and find them under their own label, or delete them for good.
- **Reactions.** Click a reaction again to remove it, and hover to see who reacted.

## Agents that see long work through

- **Background tasks.** Agents can start long work in the background, wait for it, and wake up when it finishes.
- **Hand-offs that come back.** When an agent hands work to another agent, it follows that work and acts on the result. Replies from long-running projects are no longer lost after 20 minutes.
- **Stopping and steering.** Stop now reaches tools that are waiting. The workspace agent can list your running agents and stop them.
- **Fewer failed turns.** If a model returns an empty reply, the agent retries once instead of giving up. When memory runs low, the largest command stops instead of the whole turn, and a runtime with work in progress isn't shut down.
- **Smarter defaults.** Every plan now defaults to Auto, which picks the right model for each task. Claude Haiku 5.5 is available, and workspace admins can set the default model for tagged agents.
- **More tools.** Agents can look up Instagram and TikTok profiles, and the browser tool can test different screen sizes and read console and network errors.

## Roles and permissions for teams

- **Roles for workspaces and projects.** Decide who can view, edit, and manage each workspace and project. Only a workspace owner can manage the owner role.
- **Agents act within your access.** An agent's tools have the same project permissions as the person who asked.
- **Shared GitHub account.** Share your GitHub account with all of a workspace's agents, so each one doesn't need its own connection.
- **Your own workspace agent chats.** Each member gets their own chats with the workspace agent.

## A faster start

- **Start with what you want to build.** Onboarding now asks "What do you want to build?" instead of having you pick an agent or choose between a personal and team workspace.
- **Ready when you are.** Your workspace agent warms up during onboarding, so your first message gets a quick reply.
- **Faster cloud projects.** Cloud projects wake up faster after they've been idle.
- **No interruptions from updates.** Updates to the cloud runtime now reach a project once it has been idle, so a project you're using isn't restarted under you.
- **Safer git history.** Projects save git history in small increments, so saves are faster and more reliable. Git LFS works in cloud projects.

## Also in this release

- **Desktop.** Upgraded to Electron 44 with lower memory use and a faster start. Local and cloud workspaces appear side by side, and you can sign in and out from the workspace switcher. On Windows, Shogo no longer flashes console windows.
- **Activity.** Filter #activity by agent and channel, and open any line in the chat where it happened.
- **Analytics.** Usage and cost analytics have their own screen, and work on desktop too.
- **Mobile.** Clearer colors in chat formatting, the system photo picker (no broad photo access), and the Get started checklist in the sidebar.
- **Upgrades when you need them.** Hitting a usage limit or the Pro publishing gate now shows an Upgrade option instead of a dead end.

## Fixed

- Notifications now arrive on web and iOS.
- The unread badge no longer comes back after you read a channel.
- Pasted lists and tables keep their formatting.
- Link previews work for large pages and no longer show empty cards.
- Share links work from workspace agents and no longer fail on temporary errors.
- Projects no longer hang on "Starting your project".
- Remote SSH projects start and reopen reliably.
- Shell commands can use `sudo`.
- "Follow agent" in the IDE no longer opens files and switches tabs on its own.
- Long meeting recordings transcribe in full.
