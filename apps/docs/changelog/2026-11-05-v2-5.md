In 2.5, your Personal workspace follows you to every device, and workspaces move between your computer and the cloud. Published apps scale to zero and back. Chat keeps up when you reload, switch tabs or type fast, and the IDE sends code to the agent in one keystroke.

<!-- truncate -->

## One workspace, every device

- **One Personal workspace.** Your Personal workspace is the same on the web, on every desktop you sign in to, and on your phone. If a desktop already had its own Personal, its chats and files are folded into the shared one. Nothing is deleted, and its scheduled jobs keep running on that computer.
- **Move a workspace.** Move a whole workspace, or only the channels and agents you pick, from desktop to cloud or back, in one flow you can resume. The original stays behind with a "Moved to" banner.
- **Your computer's workspaces on the web.** A workspace on your desktop works from Shogo on the web like any cloud workspace, and reconnects when the desktop restarts.
- **Your computer stays yours.** Agents can use a paired computer only for its owner, from their Personal workspace, and only when device tools are switched on.

## Publishing that scales

- **Scale to zero.** Published apps sleep when nobody is using them and wake on the next visit. Keep an app always on, or set how far it can scale, within your plan.
- **Staging.** On Pro and above, give an app a staging environment next to production.
- **Custom domains.** The Publish menu links straight to Settings > Custom domain, and your agent can walk you through putting an app on your own domain.
- **Publish from desktop.** The desktop app builds your app on your computer and the cloud hosts it.
- **Forms work.** An app that posts to its own API from the browser works in preview and once published.

## Chat that keeps up

- **Reload-proof.** Reload the page, press Back, or open the chat in a second tab while the agent is replying, and the running turn is still there and still streaming.
- **Edit and resend.** Edit an earlier message in place and send it again.
- **Drafts per chat.** Each chat keeps its own unsent draft and model choice.
- **Faster.** Typing in a long chat no longer lags, chat history is kept on your device so it opens straight away, and a chat you return to mid-reply stays in order.
- **Bigger files.** Attach up to 100 MB in an agent chat, and zips and large videos upload intact.
- **Video.** Attach a short video and GLM 5.3 Flash can watch it and answer questions about it.
- **Failures that explain themselves.** A failed turn keeps your prompt and the reply so far, and tells you what happened instead of showing a raw provider error.

## Add to Chat in the IDE

- **Send code to the agent from anywhere.** Drag a file in, select lines and press Cmd/Ctrl+L, or right-click and choose Add to Chat.
- **Root-cause planning.** Ask the agent to plan a fix and it traces the bug to its cause first.

## Better on your phone

- **Smoother motion.** Navigation, Back and tab switches feel consistent across the app.
- **Channels.** A channel opens at the latest message, with an "N new" pill back to what you haven't read. The channel header has tabs, like Slack.
- **Notifications.** Android notifications arrive when the app is in the background or closed. iOS plays voice notes recorded on the web.
- **Reading.** Phone chat uses one type scale and an even paragraph rhythm.

## Also in this release

- **Cheaper heartbeats.** Each heartbeat starts a fresh session on the model you chose, instead of re-sending the whole history every time.
- **Clearer spend.** Usage shows model cost and the Shogo fee separately, and names the model that actually ran.
- **Google models.** Add a Gemini API key for Google models and Lyria music.
- **Analytics.** Admin analytics pages open in seconds and load panel by panel. The desktop usage chart shows real daily spend.
- **Channels and DMs.** One thread open at a time, mentions survive edits, and replies in DM threads reach the other person's Activity.

## Changed

- **Media needs funds first.** Images, music, 3D and video run only if the workspace can pay for them, and video generation needs a paid plan.
- **Files.** The file viewer has an icon-only Download button and a shareable link to the file.

## Fixed

- An empty file upload is refused with a clear message instead of being stored as 0 bytes.
- The update banner counts running agents correctly.
- Desktop file links open the file on disk directly.
- A preview link from the agent is always the https preview address.
- The sign-in headline no longer overlaps itself with reduced motion on.
