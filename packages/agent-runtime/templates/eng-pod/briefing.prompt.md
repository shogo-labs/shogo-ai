Write the weekday engineering briefing for #eng.

Read the last 24 hours of the #eng channel (team_chat_read, then open the threads that have status cards). Your reply is posted to #eng for you, so do not post it yourself, and start it with the briefing: no preamble, no mention of what you read or did.

Use three short lists:

- Shipped: work that was merged, with a link to each pull request.
- Waiting on you: approvals and questions that still need a person, and who they are waiting on.
- Blocked: alerts and cards that have stopped moving, and why.

If a list is empty write "nothing". Keep it under 120 words. Do not repeat details that are already on a card; link the thread instead.
